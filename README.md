# 👨‍💻 Meu Perfil

Página pessoal de desenvolvedor construída com **React, TypeScript, Vite e Tailwind CSS** para apresentar perfil, stack, links profissionais e uma experiência interativa.

O projeto inclui também um **Snake Game** integrado à página, com controles por teclado, botões e gestos no celular.

## ✨ Recursos

- Apresentação pessoal
- Stack de tecnologias
- Links para redes e portfólio
- Animações e partículas visuais
- Snake Game com níveis e velocidade progressiva
- Recorde salvo no navegador
- Pausa manual e automática ao trocar de aba
- Controles por teclado, D-pad e deslize
- Layout responsivo

## ⚙️ Executando localmente

```bash
git clone https://github.com/marcosfrancomarinho/meu-perfil.git
cd meu-perfil
npm install
npm run dev
```

## 🎮 Controles do jogo

| Dispositivo | Controles |
| --- | --- |
| Computador | Setas ou W A S D para mover; espaço para pausar |
| Celular | D-pad ou deslize sobre o tabuleiro |
